# Glossário canônico do ReqSys

Este glossário é a fonte inicial de nomenclatura para artefatos novos ou modificados.

| Termo canônico | Termo externo ou legado | Uso recomendado |
|---|---|---|
| demanda | request | Unidade de trabalho recebida para análise |
| requisito | requirement | Necessidade validável do produto |
| parecer | opinion, assessment | Resultado fundamentado de uma análise |
| apontamento | finding | Registro de inconformidade ou observação |
| fila de atendimento | service queue | Conjunto ordenado de demandas disponíveis |
| disponível | available | Demanda apta a ser reservada |
| reservada | reserved | Demanda atribuída temporariamente |
| em atendimento | in progress | Demanda com execução iniciada |
| concluída | completed | Demanda finalizada |
| responsável | owner, assignee | Pessoa ou serviço responsável |
| situação | status | Estado de negócio atual |
| correlação | correlation | Identificador para rastreabilidade ponta a ponta |
| prontidão | readiness | Capacidade de receber tráfego |
| vivacidade | liveness | Evidência de que o processo está ativo |
| painel | dashboard | Visão consolidada de indicadores |
| alerta | alert | Comunicação de condição relevante |
| evidência | evidence | Registro verificável de uma execução ou decisão |
| solicitação de alteração | pull request | Proposta versionada de mudança |
| ramificação | branch | Linha isolada de desenvolvimento |
| confirmação | commit | Registro versionado de uma alteração |
| fluxo de trabalho | workflow | Automação composta por etapas |

## Regra de uso

O nome técnico oficial pode ser apresentado entre parênteses na primeira ocorrência quando necessário. Identificadores impostos por ferramentas, protocolos e contratos externos não devem ser traduzidos.
