Copilot Memory — modo corporativo simples

Sem Dataverse, Power Apps, API personalizada ou SQL Server.

Use em 4 passos

  1. Envie CopilotMemory.xlsx para SharePoint ou OneDrive.
  2. Preencha configuracao/CONFIGURAR.json.
  3. Crie os 3 fluxos usando PROMPTS_POWER_AUTOMATE.txt ou os JSONs de powerautomate/.
  4. Adicione a planilha ao Copilot Notebook e teste com uma unica tarefa.

Fluxos

  1. 1. Copilot Memory Restrito - Planner para Excel — Recorrencia a cada 15 minutos
  2. 2. Copilot Memory Restrito - Excel para Planner — Recorrencia a cada 15 minutos
  3. 3. Copilot Memory Restrito - Saude — Recorrencia a cada 60 minutos

Teste de aceite

Crie 1 tarefa no Planner, rode Planner→Excel, confirme uma linha em tbMemoriaCopilot, solicite uma alteracao em tbAtualizacoesPlanner com AtualizarPlanner=SIM, rode Excel→Planner e confirme o evento em tbHistoricoCopilot. Execute novamente e confirme ausencia de duplicidade.

AUTOTESTE.json valida a estrutura do pacote. A conexao real com o tenant deve ser validada em DEV.
